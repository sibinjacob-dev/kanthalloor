# Kanthalloor Tourism Website

A static tourism website for Kanthalloor and Marayoor, Kerala.

## Project structure

```text
.
|-- index.html
|-- assets/
|   |-- css/
|   |   `-- styles.css
|   `-- images/
`-- README.md
```

## Run locally

Open `index.html` directly in a browser, or serve the repository root with any static file server.

## Conventions

- Page markup lives in `index.html`.
- Shared styles live in `assets/css/`.
- Local image assets live in `assets/images/`.
- Use relative paths so the site works locally and on static hosting.
